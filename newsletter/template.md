# Issue template

Phase 0: no pulse, poll, reply survey, or other answer collection. Pulses start only after the deletion check in spec 01.

- **Practice:** one thing to try this week
- **Tool or mode tip:** one habit for a tool or for learning / onboarding / delivery
- **Stuck of the week:** a paraphrased theme, never a quoted submission
- **Changelog:** what changed in the project

Cadence on the page is every two weeks. If we fall back to monthly, that is a new consent version before more sign-ups.
