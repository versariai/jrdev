## Emails sent by Buttondown (free plan: default text, not editable)

Custom transactional emails need Buttondown's Standard plan, so v2 uses the defaults. These are Buttondown's published default templates, not yet checked against a fixture inbox. If a fixture shows different wording, paste the inbox text here and bump the consent version.

**Confirmation** ([docs](https://docs.buttondown.com/transactional-emails-confirmation)):

```
Hi there!

Thanks for subscribing to {{ newsletter.name }}. To complete your subscription, please click the link below:

{{ confirmation_url }}

About {{ newsletter.name }}:
{{ newsletter.description }}

If you didn't subscribe to {{ newsletter.name }}, you can safely ignore this email.
```

**Reminder** (one, to unconfirmed sign-ups after 24 hours; [docs](https://docs.buttondown.com/transactional-emails-reminder)):

```
Hi there,

We noticed you haven't confirmed your subscription to {{ newsletter.name }} yet.

To start receiving our updates, please click the link below to confirm:

{{ confirmation_url }}

About {{ newsletter.name }}:
{{ newsletter.description }}

If you didn't sign up for this newsletter or you're no longer interested, you can safely ignore this email.
```

**Welcome** (after confirmation; [docs](https://docs.buttondown.com/transactional-emails-welcome)):

```
Welcome to {{ newsletter.name }}!

Thank you for confirming your subscription. We're excited to have you join our community.

What to expect:
{{ newsletter.description }}

You can manage your subscription preferences here: {{ manage_subscription_url }}

If you ever want to unsubscribe, you can do so here: {{ unsubscribe_url }}
```

If the plan changes and these become custom, that's a new consent version.
